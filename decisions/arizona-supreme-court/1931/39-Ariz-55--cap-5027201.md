# State v. Perry

## Majority (PER CURIAM.)

PER CURIAM.
This case involves the validity and constitutionality of the current wage statute (sec. 1350, Rev. Code 1928), and is controlled by the decision in case No. 761, State v. Jay J. Garfield Building Co., ante, p. 45, 3 Pac. (2d) 983, just decided.
The judgment is affirmed.
